# VPN-bot — Финальная продуктовая архитектура

> Опорный документ: целевое видение продукта и системы. Строим поэтапно (см. §9 «Этапность»), но проектируем сразу под эту картину.
> Последнее обновление: 2026-06-02.

---

## 0. Что это за продукт

Telegram-бот (+ сайт + позже приложение), который продаёт подписки на VPN, устойчивый к DPI/блокировкам мобильных операторов и РКН. Главная миссия: **человек должен легко получить качественный рабочий VPN на любой сети**.

Ключевые продуктовые принципы:
- Конфиг отдаётся **ссылкой-подпиской** (авто-обновление), а не статичным QR — чтобы менять бэкенд (сервера, IP, ключи, локации) без участия пользователя.
- Несколько **тарифов по плотности**: общий → индивидуальный (≤N на ноду) → выделенный.
- Сервера поднимаются **под спрос** (автоскейлинг по API облака), а не арендуются пачкой заранее.
- Оплата возможна **вне Telegram** (сайт) — на случай, когда ТГ/оплата недоступны.

## 1. Тарифы

| Тариф | Что это | Технически | Цена |
|---|---|---|---|
| **Пробник (Trial)** | 10 ГБ / N дней, выдаётся при старте | юзер в панели с квотой | бесплатно |
| **Общий (Standard)** | одна ссылка-подписка, все общие локации (модель SaveVPN) | shared-ноды, sub-URL, лимит трафика/устройств | низкая |
| **Индивидуальный (Premium)** | премиум-нода на ≤N человек, выбор локаций, опц. статичный IP | premium-пул с кэпом, автоскейл, `sendThrough` для static-IP | x2–3 |
| **Выделенный (Dedicated)** | свой VPS, статичный IP | 1 юзер = 1 сервер | топ |

- Длительности: 1 / 3 / 6 / 12 мес.
- Всем тарифам выдаётся **ссылка-подписка** (авто-обновление каждые ~3 ч), не статичный QR.
- Лимиты на подписку: **трафик** (ГБ), **срок**, **число устройств**.

### Статичный IP (для Premium/Dedicated)
- **Вариант A (Dedicated):** выделенный VPS на пользователя — egress-IP всегда один. Дорого.
- **Вариант B (Premium со статикой):** один сервер с несколькими купленными IP + Xray `sendThrough` — каждому премиум-юзеру закреплён **свой** статичный egress-IP на общем железе. Дёшево и масштабируемо.
- Важно: статик-IP **несовместим с ротацией ноды** — такие ноды стабильные (длинная аренда, фикс-IP), а не эфемерные.

## 2. Структура бота (экраны)

**Главный кабинет:**
- 👤 **Профиль** — имя, ID, баланс ₽
- 🔑 **Моя подписка** — тариф, трафик X/Y ГБ, устройства, срок, статус, ссылка-подписка
- 🛒 **Купить / Тарифы** → тип → срок → опции (локация, статичный IP) → оплата
- 🔄 **Продлить подписку**
- 📲 **Подключить устройство** — приложения (V2RayTun / Streisand / Hiddify / sing-box) + QR + ссылка + диплинки импорта
- 🌍 **Локации** (Premium — выбор/смена)
- 💳 **Пополнить баланс**
- 🎁 **Промокод**
- 🤝 **Партнёрская программа** — реф-ссылка, статистика, начисления на баланс
- 📖 **Инструкции** · 💬 **Поддержка** · ⚙️ Язык

**Админ-панель (в боте):**
- Ноды: список, регион, tier, ёмкость (X/N), статус, ручной add/remove/teardown
- Пользователи / подписки, поиск
- Статистика: выручка, активные, по локациям, нагрузка нод
- Рассылки, промокоды, ручной автоскейл

## 3. Архитектура системы

```
   ┌─ Telegram-бот (aiogram) ─┐
   ├─ Сайт-портал (Next.js) ──┤──►  БИЛЛИНГ/АККАУНТ (общее ядро, API)
   └─ Приложение (позже) ─────┘            │
                                           ▼
                                ПАНЕЛЬ (Marzban / Remnawave)
                                - юзеры, подписки, лимиты
                                - sub-сервер (ссылка-подписка)
                                - API управления нодами
                          ┌────────┬────────┬────────┐
                        node NL  node DE  node RU ...   ← Xray: VLESS+Reality (+ Hysteria2)
                          ▲
                          │ АВТОСКЕЙЛЕР ──► API облака (Vultr / Hetzner / Aeza)
                          │  поднять/удалить ноду по спросу + setup.sh (cloud-init)
```

**Компоненты:**
- **Бот** — фронт продаж/кабинета.
- **Сайт-портал** — второй фронт (оплата вне ТГ при истёкшей подписке), тот же биллинг.
- **Биллинг-ядро** — общее для бота и сайта (БД + сервисы).
- **Панель (Marzban/Remnawave)** — раздаёт подписки, считает трафик/срок/устройства, управляет нодами через API.
- **Ноды** — Xray (VLESS+Reality основной, Hysteria2 доп). Локация = нода. У ноды есть `tier` (shared/premium).
- **Автоскейлер** — сервис: следит за ёмкостью, через API облака поднимает/удаляет сервера, прогоняет `setup.sh`, регистрирует ноду в панели.
- **Платежи** — CryptoBot + карты (PSP) + баланс-кошелёк (+ опц. Telegram Stars).
- **Клиенты** — V2RayTun / Streisand / Hiddify / sing-box; позже свой брендированный клиент (обёртка над sing-box).

### Почему такой стек (а не наш текущий AmneziaWG)
- Рынок (SaveVPN и др.) и индустриальный ответ на DPI — **VLESS+Reality** (маскировка под настоящий TLS) + **панель** с мульти-нодой и подписками.
- Панель из коробки даёт: мульти-локацию, ссылки-подписки, лимиты трафик/срок/устройства, REST API.
- Текущий **AmneziaWG** рабочий (см. PROJECT_CONTEXT.md), но плохо масштабируется под мульти-локацию/тарифы. Решение: ядро провижининга переезжает на панель; AmneziaWG — убрать или оставить одним из протоколов.

## 4. Модель данных (ядро)

- **User**(id, tg_id, username, balance, lang, referrer_id, ref_code, created_at)
- **Subscription**(id, user_id, **tier**, panel_username, sub_token, traffic_limit, traffic_used, device_limit, **expires_at**, status, **node_ids/region**, static_ip, created_at)

- **Payment**(id, user_id, amount, currency, provider, status, purpose, external_id, created_at)
- **BalanceTx**(id, user_id, amount, type[topup/spend/referral], ref, created_at)
- **PromoCode**(code, type, value, usage_limit, used, expires_at)
- **Plan/Tariff**(code, tier, duration_days, price, traffic_gb, device_limit) — конфиг тарифов

## 5. Ключевые сценарии

1. **Старт** → авто-пробник (панель `create_user` 10 ГБ / N дней) → ссылка-подписка.
2. **Покупка** → тип → срок → опции → оплата (баланс/крипта/карта) → панель create/extend → автоскейлер гарантирует ноду → ссылка.
3. **Премиум-провижининг** → сажаем на премиум-ноду с `count < cap`; нет места/локации → автоскейлер поднимает сервер (облако API → `setup.sh` → регистрация в панели) → сажаем.
4. **Продление** → панель продлевает срок / сбрасывает трафик.
5. **Истечение** → панель отключает; **teardown**: премиум/выделенная нода опустела → автоскейлер удаляет сервер (перестаём платить).
6. **Реферал** → реф-ссылка; приглашённый купил → процент рефереру на баланс.
7. **Оплата на сайте** → то же ядро → панель обновляет подписку.

## 6. Деньги и сервера (автоскейлинг)

Не арендуем сервера пачкой заранее. Используем **API облачных провайдеров** (Vultr 25+ регионов, Hetzner, DigitalOcean, Aeza) — создание/удаление за ~1–2 мин, биллинг по часам.

- **Тёплый минимум** в 2–3 топ-регионах — для мгновенной выдачи.
- **Provision-on-demand:** нода заполнилась до кэпа (например 8/10) → заранее поднимаем следующую; редкую локацию — под заказ с UX «готовим сервер ~2 мин».
- **Teardown-on-expiry:** подписки на ноде кончились → удаляем сервер.
- Правило ценообразования: **цена тарифа > стоимость доли сервера + маржа**. Премиум дороже, т.к. покрывает неполную загрузку.

Итог: платим за сервер только пока на нём есть платящий пользователь; расходы растут вместе с выручкой, без большого аванса.

## 7. Сайт и приложение (оплата вне Telegram)

**Сайт-портал — приоритет.** Личный кабинет + оплата картой/криптой без комиссии Apple и без ревью. Вход через Telegram Login Widget или email. Тот же биллинг-API, что и бот.

**Приложение в App Store — осторожно:**
- Apple за цифровые подписки требует свой IAP и берёт 30%; прямые ссылки на оплату внутри приложения отклоняют.
- Рабочая схема: **оплата на сайте, приложение = просто VPN-клиент с логином в аккаунт** (login-based, без покупки внутри).
- Поэтому: сайт сейчас, приложение-клиент позже.

**Подводный камень:** сайт должен открываться в РФ **без VPN** — «чистый» домен, устойчивый хостинг, несколько зеркал/доменов на случай блокировки.

## 8. Структура кода бота (эволюция текущего проекта)

```
bot/handlers/   start, cabinet, tariffs, connect_device, locations,
                referral, balance, promo, instructions, support, admin/*
bot/keyboards/  меню, выбор тарифа/локации/срока
bot/middlewares/ auth/подписка, throttling
services/       panel_client (API Marzban)        ← вместо awg
                autoscaler (API облака + setup.sh)
                billing, payments/(cryptobot, card_psp, balance)
                referral, promo, subscription, deeplinks/qrcode
database/       models, repository (Users, Subs, Servers, Payments, Balance, Promo)
scheduler/      poll_payments, check_expiring, deactivate_expired,
                autoscale_check (подъём/teardown), traffic_sync, referral_payouts
web/            отдельное приложение Next.js (тот же биллинг-API)
```

### Фоновые задачи (scheduler)
- **poll_payments** — проверка оплат (крипта/карты).
- **traffic_sync** — тянуть из панели расход трафика/устройства → кабинет, отключение при превышении.
- **check_expiring / deactivate_expired** — напоминания о продлении, отключение.
- **autoscale_check** — держать запас ёмкости в премиум-пуле, удалять пустые ноды.
- **referral_payouts** — начисления.

## 9. Этапность

- **MVP:** Общий тариф на Marzban + ссылка-подписка + кабинет + оплата (крипта) + пробник. Уже продаётся.
- **Этап 2:** Премиум-пул ≤N + автоскейлер (облако API) + выбор локаций.
- **Этап 3:** Сайт-портал (оплата вне ТГ) + карты + реферралка + промокоды.
- **Этап 4:** Статичный IP / Dedicated, приложение-клиент, мульти-протокол (Hysteria2).
