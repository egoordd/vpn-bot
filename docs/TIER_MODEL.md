# Модель тарифов (по плотности)

> Зафиксировано 2026-06-17. Тарифы различаются **плотностью** (сколько людей на
> ноду) и стабильностью IP, а НЕ количеством локаций.

| Тариф | Плотность | IP | Локации | Статус |
|---|---|---|---|---|
| **Общий** | высокая (много людей/ноду) | плавающий | **несколько, переключение в приложении** | ✅ работает |
| **Premium** | низкая (≤N людей/ноду) | стабильный/фиксированный | твоя страна | ⏸ скоро (нужна отдельная нода) |
| **Dedicated** | 1 юзер = 1 сервер | выделенный личный IP | твой выбор | ⬜ Фаза 4 |

## Ключевая идея
- **Переключение между локациями — фича Общего тарифа** (как у всех VPN: один
  набор серверов, выбираешь в клиенте). Не за это берут деньги в Premium.
- **Premium продаёт разгруженность + стабильный IP**, а не количество стран.
- **Dedicated** — личный сервер с выделенным IP (под банки/whitelisting).

## Как реализован Общий = мульти-локация (Marzban)
- Каждая нода = одна локация со своим inbound (own-domain Reality: свой dest/SNI/
  ключи под её IP). Сейчас: `VLESS Reality 443` (🇺🇸 США, главный сервер),
  `VLESS Reality AMS` (🇳🇱 Нидерланды, нода Amsterdam).
- `MARZBAN_DEFAULT_INBOUNDS` = **оба inbound'а** → каждый стандартный юзер
  получает обе локации в одной подписке. Клиент (Happ/V2RayTun) переключает
  сервер сам.
- Имена серверов в подписке = remark хостов: `🇺🇸 США`, `🇳🇱 Нидерланды`.
- Добавить локацию = поднять ноду (скрипт `reality_smoketest.sh`), завести как
  Marzban-node + inbound + host, дописать тег в `MARZBAN_DEFAULT_INBOUNDS`.

## Premium на паузе (почему)
Чтобы дать «мало соседей», premium-ноды должны быть **отдельными** от
общего пула (нельзя одну ноду сделать и «много людей», и «мало людей»). Сейчас
обе ноды отданы в общий пул. Premium включим, когда добавим выделенную
низкоплотностную ноду (с лимитом юзеров + автоскейл).

Код premium НЕ удалён, только закрыта продажа:
- `bot/handlers/buy.py`: premium-входы → `PREMIUM_SOON_TEXT`.
- Спящая машинерия: `MARZBAN_REGION_INBOUNDS`, premium-lane (`tg_<id>p`),
  `switch_premium_region`, premium-карточки. Включается обратно при появлении
  premium-ноды.

## Чтобы вернуть Premium
1. Поднять выделенную низкоплотностную ноду в стране X (`capacity`=N).
2. Завести её как Marzban-node + отдельный premium-inbound + host.
3. `MARZBAN_REGION_INBOUNDS` = {"x": {...}}; убрать premium из общего
   `MARZBAN_DEFAULT_INBOUNDS` (premium-ноды не для общего пула).
4. Снять «скоро» в `buy.py` (вернуть premium tier + region picker).
5. Capacity/автоскейл: при заполнении premium-ноды поднимать новую (Фаза 2 код).
