# Детальный план следующих шагов (после live e2e бота)

> Составлен 2026-06-12. Точка отсчёта: Reality live-проверен на iPhone/LTE; бот
> запущен локально против живого Marzban, /start выдаёт пробник и sub-ссылку;
> Фаза 3 backend (кошелёк/рефералка/промо + billing_api + FastAPI) готов на
> тестах; сайт (лендинг+кабинет) собран на моках.

## Трек A — Дозакрыть MVP-гейт (пункт 24) — БЛОКЕР

**Что осталось.** Сам факт «бот отвечает» — не приёмка. Гейт закрывается только
полной цепочкой на телефоне.

1. **A1. Приёмка пробника** [нужен пользователь]: /start → «Подключить
   устройство» → импорт ссылки в Happ → LTE → браузинг работает.
2. **A2. Приёмка оплаты** [нужен CRYPTOBOT_TOKEN]: покупка standard_1m через
   CryptoBot (можно минимальный тестовый инвойс) → poll подтверждает → подписка
   продлена в Marzban → срок в кабинете бота увеличился → рефералка начислилась
   (если есть реферер).
3. **A3. Регресс после оплаты**: трафик-синк тянет usage из панели.

**Acceptance:** скриншот браузинга по LTE + запись в payments со status=completed
+ expires_at сдвинут.

## Трек B — Прод-инфраструктура бота (фикс «всё медленно» по-настоящему)

Сейчас бот живёт на Маке за РФ-сетью — long-poll к Telegram душится, любое
действие 3–10с. Прод-решение из плана: бот на VPS вне РФ.

1. **B1. VPS** ~1 GB RAM (Vultr $6/мес — заодно живая проверка Vultr API из
   Фазы 2: создать инстанс через `scripts/vultr_contract_probe.py` /
   autoscaler-код, а не руками!). Ubuntu 24.04.
2. **B2. Деплой**: docker compose (bot+postgres+redis) — уже готов и починен
   (MARZBAN_* прокинуты); `.env` переносится; `alembic upgrade head` в
   entrypoint уже есть. Образ собирать на VPS (amd64) — там это минуты.
3. **B3. Бэкапы**: cron `pg_dump | gzip` ежедневно + копия на Mac (scp) или в
   объектное хранилище. Восстановление задокументировать (1 команда).
4. **B4. Мониторинг-минимум**: healthcheck-скрипт (бот отвечает на getMe;
   панель отвечает; место на диске) + телеграм-алерт админу через того же бота.
5. **B5. Billing API туда же**: `uvicorn services.http_api:app` за nginx
   (или просто на 127.0.0.1 + nginx proxy_pass), BILLING_API_TOKEN обязателен.

**Acceptance:** /start из Telegram отвечает <1.5с стабильно; рестарт VPS
поднимает всё само (restart: unless-stopped); pg_dump восстановим.

## Трек C — UX кошелька/промо/рефералки в боте (сервисы готовы, кнопок нет)

1. **C1. «💰 Кошелёк»** в главном меню: баланс (`get_account_overview`),
   5 последних операций, кнопки «Пополнить» / «Промокод».
2. **C2. Пополнение**: выбор суммы (150/300/600/произвольная FSM) → CryptoBot
   инвойс с payload `topup:{user_id}:{amount_kopecks}:{uuid}` → poll задетектил
   оплату → `wallet.deposit(kind=deposit)`. **FX**: конфиг `RUB_PER_USDT`
   (вручную обновляемый курс) для пересчёта суммы инвойса. Честный TODO.
3. **C3. Оплата тарифа с баланса**: в buy-флоу, если `balance >= price`, кнопка
   «Оплатить с баланса (N₽)» → `wallet.spend(reference=plan:{code}:{uuid})` →
   `activate_access` → при сбое панели — компенсирующий `deposit(kind=refund)`.
4. **C4. Промокод**: FSM-ввод кода → `redeem_balance_promo` (бонус на баланс) с
   человеческими ошибками («истёк», «уже использован»...).
5. **C5. Рефералка**: кнопка «👥 Пригласить» → ссылка `?start=ref_{code}` + QR +
   статистика; в `/start` — парсинг `ref_` payload → `attach_referrer`
   (молча игнорировать ошибки самопривязки). Начисление при оплате уже
   встроено в scheduler.
6. **C6. Тесты** всех новых хэндлеров (паттерн test_handlers_*).

**Acceptance:** полный круг на живом боте: промо WELCOME → баланс → оплата
тарифа балансом → продление в панели; реф-ссылка приводит друга, после его
оплаты у реферера +20%.

## Трек D — Сайт: вход и живые данные

1. **D1. Magic-link через бота** (без паролей и SMS):
   - таблица `login_tokens(token_hash, user_id, expires_at, used_at)` +
     миграция 0004;
   - в боте кнопка «🌐 Войти на сайте» → бот создаёт одноразовый токен (TTL
     10 мин) → ссылка `https://site/auth?token=...`;
   - billing API: `POST /auth/exchange {token}` → одноразово гасит токен,
     возвращает `{userId}`;
   - Next.js: route handler ставит httpOnly cookie (подписанный JWT,
     секрет = env), кабинет читает user_id из сессии вместо demo=1.
2. **D2. Live-режим кабинета**: BILLING_API_URL на прод-API (B5); фоллбек на
   моки остаётся для dev.
3. **D3. Домен** [нужно решение пользователя]: купить чистый домен. Он нужен
   сразу трём вещам: сайт без VPN, Telegram Login (BotFather требует домен),
   и **фейловер нод** (подписки должны указывать на `nodeN.domain`, а не на
   IP.sslip.io — тогда замена умершей ноды = смена A-записи, конфиги юзеров
   не меняются).
4. **D4. Деплой сайта**: Vercel (быстрее всего) или nginx на VPS из трека B.
5. **D5. Болванки** оферты/privacy + robots/sitemap.

**Acceptance:** вход из бота в кабинет на проде; кабинет показывает реальные
баланс/подписку/рефералку.

## Трек E — Платежи

1. **E1. CryptoBot live** [нужен токен от @CryptoBot → пользователь].
2. **E2. Пополнение кошелька** — см. C2.
3. **E3. Карточный PSP (РФ)** [нужно решение]: кандидаты YooKassa / Robokassa /
   Lava. Все требуют юр. статус (самозанятый/ИП) — вопрос к пользователю.
   Архитектура: оплата на сайте → webhook PSP → billing API
   `POST /payments/psp/webhook` (подпись!) → activate/deposit. В боте кнопка
   «Оплатить картой» = ссылка на сайт с предзаполненным тарифом.

## Трек F — Ядро VPN: устойчивость и уникальность

1. **F1. Мульти-протокольная подписка** (Reality + Hysteria2 авто-fallback):
   собственный sub-эндпоинт в billing API (`GET /sub/{token}`), который отдаёт
   Happ/sing-box JSON c обоими протоколами и urltest-селектором. База уже есть
   в `services/client_profiles.py` — вычистить от burstObservatory/balancer
   мусора, покрыть тестами, переключить бота на свою ссылку. Это и есть
   «само чинится» для юзера.
2. **F2. Status-page по операторам** (уникальность №1 на рынке): пробы
   TCP/TLS connect к ноде:443 из реальных RU-сетей через **RIPE Atlas**
   (дёшево/бесплатно) + страница на сайте «работает ли у твоего оператора
   прямо сейчас». MVP: cron-скрипт → JSON в billing API → виджет на лендинге.
3. **F3. Cold-standby нода**: второй дешёвый VPS с пресетом (egress-политика,
   nginx+LE, xray) + рунбук фейловера. Требует домен (D3): фейловер = смена
   A-записи.
4. **F4. Авто-ротация при DPI-событии** (после F2): детект деградации проб →
   скрипт ротации shortId/ключей + новый серт → подписки обновляются сами.
