# Etalon VPN — собственная установка заказчика (15.10.2026)

Проект на заказ: серверы на аккаунте заказчика (4vps.su), с нашей инфраструктурой не связан.
Доступ — ключ `etalon-setup` (у нас `~/.ssh/etalon_ed25519`), вход по паролю закрыт на всех серверах
(`/etc/ssh/sshd_config.d/01-keyonly.conf`).

| Сервер | Роль |
|---|---|
| 89.221.203.114 (Москва) | вход для пользователей: marzban-node (VLESS Reality 443 / 2053 / 2083), nginx (подписки, панель, позже сайт), клиенты Hysteria2 к выходам |
| 147.45.50.226 (Нидерланды) | Marzban (docker, SQLite), шлюз подписок `etalon-gateway`, выход NL, ретранслятор для DE |

## Почему так

Из России к 147.45.50.226 и 77.110.107.198 режется TCP, начатый со стороны РФ (рукопожатие проходит,
первый байт данных — обрыв); Германия закрыта и по UDP. Пользователь поэтому подключается к
московскому серверу, а дальше трафик уходит на выход по **Hysteria2 + salamander на UDP 50000**
(~200 Мбит/с). AmneziaWG фильтр РФ узнаёт и душит (300–400 мс, 2–8 Мбит/с) — выключен.
Германия идёт Москва → Нидерланды (`hysteria-relay-de`, UDP 51820) → Германия.
TCP из Нидерландов в Москву не режется — панель сама подключается к узлу (62050/62051, ufw только для NL).

## Маршрутизация (xray_config.json панели)

- входы `VLESS NL` :443, `VLESS DE` :2053, `VLESS FR` :2083 → выходы `socks 127.0.0.1:1081/1082/1083`
  (клиенты Hysteria2 в Москве: `hysteria-nl`, `hysteria-de`, `hysteria-fr`);
- российские адреса и домены (.ru, .su, .рф, известные российские сервисы на других зонах) → `direct`
  с московского IP; частные сети и BitTorrent → `block`;
- Reality: dest `127.0.0.1:9443` (nginx с сертификатом Let's Encrypt для `89.221.203.114.sslip.io`),
  SNI то же имя, fingerprint firefox. Обычные HTTPS-запросы Reality отдаёт nginx — так работают
  подписки и панель на том же порту 443.

## Подписки

`https://89.221.203.114.sslip.io/sub/<token>` → nginx (Москва) → проброс Hysteria2 `127.0.0.1:12096`
→ `etalon-gateway` (NL, 127.0.0.1:2096) → Marzban. Happ получает JSON: «⚡️ Авто-выбор»,
«🇷🇺 Режим РУ-сервисов» и по пункту на страну; остальные — base64. Истёкшая подписка — пусто.
Настройки шлюза — `/etc/etalon/gateway.env` (пример — `gateway.env.example`).

## Панель

`https://panel.89.221.203.114.sslip.io/dashboard/` → nginx → проброс `127.0.0.1:18000` → Marzban
(слушает только 127.0.0.1:8000 на NL). Администратор — из `/opt/marzban/.env` (SUDO_*), у бота —
отдельная учётка без прав sudo.

## Бот

@etallonvpn_bot работает на NL: код в `/opt/etalon/bot` (архив собирает `make_bot_bundle.py`), служба
`etalon-bot.service`, настройки `/etc/etalon/bot.env` (`MARAT_PANEL_URL=http://127.0.0.1:8000`),
база `/var/lib/etalon-bot/users.sqlite3`. Мини-приложение — `127.0.0.1:8095`, снаружи через проброс
`18095` и nginx в Москве (`/mapp/etalon/`). Наша служба marat-vpnbot остановлена 15.10.2026.

SSH к NL из России — через Москву: проброс hysteria `127.0.0.1:2201 → NL:22`; к DE — через NL.
Лимит устройств и сброс устройств — `etalon_gateway.py devices|forget ИМЯ`.
